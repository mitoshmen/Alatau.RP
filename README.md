# Alatau.RP
Alatau Role Play — это игровая платформа на базе мобильной среды разработки, ориентированная на создание гиперреалистичного социального взаимодействия. Проект отходит от стандартных игровых скриптов в сторону полноценной системной симуляции общества с акцентом на локальную культуру и экономическую точность.
